# AGENTS.md

Convenções e contexto deste projeto para qualquer agente de codificação (Claude Code, Cursor, Copilot, Codex etc.) vivem em:

- [`docs/AGENTS.md`](docs/AGENTS.md) — stack, padrão de commits/PR, segurança, testes.
- [`docs/DESIGN.md`](docs/DESIGN.md) — identidade visual (cores, tipografia, componentes).

Leia os dois antes de trabalhar neste repositório ou em qualquer um dos submodules (`chatin-back`, `chatin-front`) — cada um tem seu próprio `CLAUDE.md`/`AGENTS.md` apontando de volta pra estes mesmos arquivos, para que não existam duas fontes de verdade divergentes.
